このアプリについて

「aimovie 投稿」(以下「本アプリ」)は、YouTube チャンネル「全日本都市伝説研究会」の運営者が、 自分で制作した動画を自分のチャンネルへ投稿するためだけに使う個人用の道具です。運営者以外の利用者はいません。

利用する Google のデータ

本アプリは、運営者本人の許可を得て、YouTube Data API を通じて次のことだけを行います。

  • 運営者のチャンネルへの動画のアップロードと、公開日時・題名・説明・タグの設定
  • 運営者のチャンネルにある予約済みの動画の公開日時の確認(投稿の時刻が重ならないようにするため)
  • 運営者が投稿した動画への、運営者自身のコメントの書き込み

データの保存と共有

  • Google の認証情報(アクセストークン)は、運営者のパソコンの中だけに保存します。外部のサーバーには送りません。
  • 取得したデータを、第三者に販売・共有・譲渡することはありません。広告や分析の目的には使いません。
  • 本アプリが Google API から受け取った情報の使用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー (限定使用の要件を含む)に従います。

許可の取り消し

本アプリへの許可は、Google アカウントの サードパーティ製のアプリとサービスからいつでも取り消せます。

お問い合わせ

YouTube チャンネル 全日本都市伝説研究会 までお寄せください。

Privacy Policy (English summary)

"aimovie 投稿" is a personal tool used only by the owner of the YouTube channel "全日本都市伝説研究会" to upload and schedule their own videos, check scheduled publish times, and post their own comments, via the YouTube Data API. OAuth tokens are stored only on the owner's computer. No data is sold, shared, or transferred to third parties, and no data is used for advertising or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
